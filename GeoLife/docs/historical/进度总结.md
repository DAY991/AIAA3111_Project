## 四、当前结果

### 完整数据（`docs/EDA_full.md`）
- **5,434,096 点 / 4,476 条标注轨迹 / 64 用户**（69 有标签用户中 5 个标签与轨迹时间不匹配，已自动跳过）
- 120s 窗口：**117,014 窗，可用 92,378（79%）**
- 10s 降采样保留率 **80.6%**（通过 go ✅；30s/60s 为压力测试，保留率 0% 属预期）
- 类别分布（点）：walk 1.59M / bus 1.28M / bike 0.95M / car 0.76M / subway 0.29M

### Core A 基线（样例 3 用户，`docs/BASELINE.md`）
- **Accuracy 0.6949，Macro-F1 0.3388**
- 逐类 F1：walk 0.83 / bus 0.70 / car 0.13 / subway 0.02 / bike 0.00
- ⚠️ bike/subway 极难（类别不均衡 + 跨用户），是后续重点
